# ส่งมอบยาให้ญาติที่มารับแทน

สไลด์บรรยายสำหรับรายวิชา PM311 ปฏิบัติการส่งมอบยา คณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์ เรียบเรียงจากการสังเกตการสอบปฏิบัติการส่งมอบยา วันที่ 14 ตุลาคม 2569

เนื้อหาแบ่งเป็น 4 บท คือ ก่อนพูดถึงยา อธิบายยาให้คนที่ไม่ได้กินเอง ปิดท้ายให้เอาไปใช้ได้จริง และกรณีศึกษาสำหรับซ้อมเป็นคู่ รวม 27 หน้า

## วิธีเปิด

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร เลื่อนหน้าด้วยปุ่มด้านล่าง ปุ่มลูกศร หรือปัดบนมือถือ ปุ่ม "สารบัญ" มุมขวาบนใช้ข้ามไปหน้าที่ต้องการ และลิงก์ตรงไปหน้าใดก็ได้ด้วย `#s5`, `#s12` เป็นต้น

ถ้าเปิด GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch `main`) จะได้ลิงก์ให้นักศึกษาเปิดดูได้โดยตรง

## หมายเหตุสำหรับผู้สอน

เวลากิน Dicloxacillin ก่อนอาหาร (แบบประเมินรอบสอบใช้อย่างน้อย 30 นาที ส่วนสไลด์ใช้ประมาณ 1 ชั่วโมง) และการแนะนำ Cetirizine แบบตามอาการ ควรให้ทีมรายวิชาตกลงกันก่อนใช้สอน
